# 單層靜態電梯

來源：`../Elevator/model.sdf`（原作者 Nick Lamprianidis）；原始檔與 metadata 保留於原資料夾。

保留第一層井道、轎廂、關閉門板及對應碰撞；移除其他樓層、外伸平台、關節、感測器及控制插件。僅作場景障礙物，不提供升降或開門功能。

模型正面朝本地 +X。外框範圍 X=[-1.10, 0.95]、Y=[-1.30, 1.30]、Z=[0, 3.20] 公尺。

## 待確認擺放方案

以目前 building.yaml 左下角外牆與上方橫牆估算，建議兩座中心分別為世界座標 (2.50, -21.60, 0)、(2.50, -24.60, 0)，yaw=0，正面朝右側走道。中心距離 3 公尺、兩座外框間隔 0.4 公尺。需要 Gazebo 視覺確認，尚未修改來源地圖或 world。

此尺寸為原尺寸；接入 props 時需針對電梯使用 scale: [1, 1, 1]，避免套用家具的全域 1.4 倍倍率。其他家具維持原倍率。
