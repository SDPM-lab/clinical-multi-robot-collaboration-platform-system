# MediSync Robot Status V6

`RobotStatusPhaseV6` · 6 秒 · 1920 × 1080 · 30 fps · 180 幀。

| 影格 | 動作 |
|---|---|
| 0–38 | 前 4 幀承接上幕最後一幀，接入固定的原站畫面。模型從第一幀完整網頁即已可見。 |
| 39–92 | 游標進入，原站清單由第 47 至 77 幀捲動 100 CSS px，煞停後在第 91 幀選取 M01。 |
| 93–149 | 橘色框依序引導中央模型、原版雙儀表與資訊區。 |
| 150–179 | 完整頁面停留，M01 維持選中狀態。 |

Shotcraft 的 `scroll-brake-moves` 用於捲動速度衰減。`draw-svg-trace` 使用單一 SVG 描邊和 dash offset，橘框沿原生 UI 邊界畫出後淡去。四組描邊的時間互不重疊。頁面以 1.125 倍 CSS 尺寸固定顯示，無攝影機位移。

原站 C01／M01 擷取來源為 2400 × 1230 PNG，顯示尺寸 1800 × 922.5，清單捲動沿用同一原站擷取的兩個捲動位置。中央是網站實際 WebGL 模型的原站定格；C01 和 M01 共用 Agibot 資產。原生儀表隨選取切換，M01 為 82%／36°C 的 Demo Telemetry。

繁中一句旁白精簡為「快速瀏覽機器人車隊，掌握每台設備的運作資訊。」配樂沿用前一版的聲音設計，只加兩個輕量捲動音及選取 Click。
