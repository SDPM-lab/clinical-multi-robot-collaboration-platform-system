# MediSync V4｜90 秒產品發表影片

本版以 V4 Master 為基礎，取代其第 13、16 節與對應的字幕、採集及驗收安排。規格為 1920 × 1080、30 fps、2,700 幀，主 Composition 為 `MediSyncLaunch90`。沿用橘、白、黑與原版 MediSync Logo。

## 母片語言與聲音

MediSyncLaunch90 重新允許繁體中文旁白，搭配繁體中文字幕、原生英文產品 UI、英文動態字卡與品牌標語 **Intelligent Care, Connected.**。旁白以明亮、自信的科技產品發表節奏說明產品價值。旁白以獨立可替換音軌混入，底樂與 UI 操作音保留獨立混音。Scene 02 V3 先參考獨立 16 秒樣片的字幕節拍，整合母片時再對齊成片切點。

| 53.5–55.5 | 游標懸停、按下並釋放 M01，點擊幀配輕觸聲。用真實選中底色和狀態更新作回饋，相機短距離平移至中央。若兩者共用模型資產，拍身份與視角重置；跨資產切換才拍重新載入。 |
| 55.5–59 | 天然 WebGL 視角從前 3/4 環繞到側前方，使用拖曳和阻尼，收尾停穩。相機交接到右上時保留機身輪廓。 |
| 59–62.5 | Focus pull 加 subtle dolly in，停在雙儀表。電量沿用原生數字與液面動畫；溫度保留真實的缺值狀態。 |

Robot Status 字幕依序標示車隊、電量與運作狀態、設備資訊及互動式三維模型。選取和部位點擊聲依畫面事件切點安排。三個價值字卡各保留 3 秒，Robot Status 維持 17 秒。

## 功能證據與採集門檻

- `RobotFleetView.vue` 與 `robotHmi.css` 已確認列表具有垂直溢出捲動，並有 hover、選中底色及選中邊線。用足量的隔離車隊資料實測 1080p 確實產生捲動。
- 選取會更新標頭、儀表與資訊。 `RobotViewport.vue` 只有在 modelAssetKey 改變時才重載，同資產會重置視角。用相容的 M01 模型實測載入與鏡頭延續。
- 中央視窗配置 OrbitControls、阻尼及平移，並有回到整機視角的按鈕。待實測拖曳、縮放、視角落點與 WebGL 採集表現。
- Battery 需要有效遙測，使用約 900 ms 數字與液面呈現。Temperature 元件支援數字與指示點動畫，但 Robot Status 目前把 motorTemperature 固定為 null，頁面會顯示「—」。字幕使用「電量、運作狀態與設備資訊」。缺值保留原生破折號。
- Information 包含 ID、樓層、位置、連線、製造商、型號與描述套件、類型、目前任務編號，以及標頭的運作狀態。遙測時間戳逾 15 秒會影響連線顯示。
- Structure 取決於模型是否支援部位組件，載入時按鈕停用。支援左臂、右臂、頭部、底座及整機。點部位會移動相機、帶出選中狀態；再點同部位回整機。先驗證 M01 的實際部位效果。
- 模擬資料維持同一後端 ID，畫面短碼才是 M01。派送建立完成後才指派，地圖以 Simulated Movement 標記。抵達時同步更新位置及 History；任務完成後目前任務 ID 可按 UI 正常清空。所有預覽與 mock 放在 `promo-video`。
- Shotcraft 採用 `cursor-flyover` 的游標先行與相機滯後、`depth-layer-moves` 的介面視差及 `spotlight-hero-card` 的局部聚焦。Match Cut 以 M01 ID、機身方向與落點客製。模型轉向與 Structure 聚焦從真實 WebGL 擷取。
- Phase B 順序沿用 V4：先 Dashboard Reveal 供確認，再 Task Creation＋Notification、PPO＋Robot Transition。把 Robot Status 動態採集納入第三項的交接驗證。進入原型前先以隔離資料完成一趟瀏覽器驗收，並確認其他 V4 前置條件（派送選點、排程編輯、PPO 輸入、地圖跟拍及歷史時間線）。本次為靜態程式檢查及企劃更新。
