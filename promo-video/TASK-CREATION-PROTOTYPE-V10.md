## 原因與修正

- V9 的表單橘／藍框以及地圖上的大選取框由影片程式的 `Anchor` 與 `RoomPulse` 加入。V10 移除這兩段，保留捕捉的原始輸入框與地標，僅在地標底下加單次圓形短亮回饋。位置在 `TaskCreationPrototypeV10.tsx` 的 `PinPulse`、`MapStage` 與 `FormAction`。原生鍵盤焦點維持原狀。
- V9 正式 MP4 有 420 個等距影格，已知 Studio 預設循環會回到開場。無法從正式 MP4 判定使用者錄影是否曾拖曳時間軸或因瀏覽器負載停頓。程式稽核沒有 Sequence 局部重置、CSS transition 或 spring，也沒有來源影片幀率問題，全部 UI 為定格素材。V9 的畫面斷續主要可定位到短時間內連接地圖遮罩、表單回切，以及通知轉清單的多圖層交接；V10 延長落位及閱讀區間、重排事件，採用同一絕對影格。
- 合法重疊只在轉場。上一畫面保留到遮罩或共享卡片完成。Priority 只插值選中底色，表單和鏡頭固定。任務列依 ID 保持掛載，Modal 關閉後只更新必要位置。
