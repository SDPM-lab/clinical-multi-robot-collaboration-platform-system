# MediSync Live Map V3.3

20 秒、1920 × 1080、30 fps。Studio Composition ID 為 `LiveMapPhaseV3-3`。

## V3.2 與 V3.3

- V3.2 的橘色滑塊四側各留 6 px，滑到下一格前後文字依模式切換。V3.3 每格 239 × 50 px，橘色與白字共用同一裁切區。只有外框有圓角，文字基線固定。滑塊在第 300／360 幀落位，與原始視角切點一致。
- 原始 WebGL 片尾第 0 幀已有正在跟拍的醫院幾何，第 63 幀才看到完整一樓鳥瞰。V3.2 第 420 幀就切換標題，第 445 幀開始加任務路線，並且晚到第 462 幀才開始加入車隊標記。這是片尾圖層排程提前，原始素材不是空白畫布。
- V3.3 第 420 幀保留與 Local Follow 對位的起始相機，沿用從近景升到完整鳥瞰的移動。片尾標題、標記、三條新路線和狀態資訊按次序加入。原場景的 M01 已有跟拍路徑可持續銜接。
- Shotcraft 的 `segmented-thumb-hero` 提供單一滑塊的移動原則，套用等寬、共用文字裁切。`line-carry-transition` 提供沿既有路徑方向傳遞視線的原則，套用到三條任務路線的描線。
