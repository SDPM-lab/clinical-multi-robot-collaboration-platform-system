# MediSync Robot Status V5

`RobotStatusPhaseV5` · 12 秒 · 1920 × 1080 · 30 fps · 360 幀。

## V4 → V5

V4 的開場只掛載抽出的車隊卡。模型圖層從第 65 幀才掛載，並受獨立的不透明度和裁切控制。陰影是獨立的 DOM 圖層，在 Studio 等待 GLB 時可以先顯示。已輸出的 V4 在主鏡頭可見模型，因此目前證據指向分鏡的顯示時序與獨立陰影，而非資產路徑錯誤。

V5 把原站截圖中的真實模型保留為底層。WebGL GLB 載入且第一次畫完後，才揭露中央原生背景與即時模型的組合。載入失敗時讓正式渲染回報錯誤。WebGL 轉場結束後，同一個原站模型畫面繼續顯示。V5 已移除獨立的投影陰影圖層。

## 取樣與聲音

原站素材依 1600 CSS px 寬、1.5× 的 Chromium 擷取尺寸輸出 2400 px，使用 CSS 等比構圖。最大縮放 1.30，低於 1.5× 擷取倍率。片尾 1600 × 930 CSS px 輸出為 2400 × 1395 PNG，原版清單完整顯示七列。運鏡使用 1186 × 996 WebGL，背景取自同頁原生 viewport。正式 MP4 採 H.264 CRF 16。

字幕與旁白在第 4–130、138–238、242–354 幀。聲音重點對齊 75 幀捲動、126 幀選取、153 幀模型聚焦及 249 幀儀表。
