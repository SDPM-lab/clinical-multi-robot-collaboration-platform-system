# MediSync Scene 02｜Precision UI Interaction Film

`TaskCreationPrototypeV2` 為 1920 × 1080、30 fps、585 幀。原版 Composition 和輸出保留供比對。V2 使用實際 Task Dispatch 擷取畫面與原生互動狀態，中文短字幕、英文產品 UI、原創合成雙聲道底樂與操作音。母片聲音規格同步採無旁白。

## Shotcraft 配方

- **cursor-flyover** 取定點操作與移動分段，游標獨立渲染。
- **icon-performance-moves / attention-bounce** 取標記局部上提、落位，以及成功通知的微彈。
- **segmented-thumb-hero** 取明確指向目標再切換原生選取狀態的節拍。
- **spotlight-hero-card** 取單一內容焦點及停留，用鏡頭裁幅聚焦原生通知。
- **shot-transitions** 取切點與視覺交接語法，以相同 T0002 從通知接入排程。

另查閱 list-reveal 與 circle-match-iris。排程直接保留原生清單，轉場維持 ID 對位。

## 功能與資料

畫面取自原有 Task Dispatch、原生地圖與路線、按鈕載入、綠色成功通知和排程的真實介面。沿用 `scripts/task-creation-demo.mjs` 以及 `src/task-creation-capture.json` 中的隔離建立和更新事件。T0002 為 `film-task-t0002`，Pharmacy → Ward A、High、未指派。已驗證的操作為 Medication 固定起點、地圖選目的地、同任務排程編輯及確認。後續指派與執行沿用相同 ID。

Task Schedule 的列表使用原生任務名稱與時間。T0002 在建立通知與重新排程確認對話框顯示。排程透過編輯欄位及確認送出，原生介面無拖曳改時段操作。Ward A 可能是類型切換後的預設候選，影片用點選後的路線描繪明確區隔候選與確認。

Studio 已以 Chromium 驗證可進入播放狀態。通知提示音的 MP4 解碼波形與第 380 幀的原始音訊事件相差約 3 ms，落在同一影格。
