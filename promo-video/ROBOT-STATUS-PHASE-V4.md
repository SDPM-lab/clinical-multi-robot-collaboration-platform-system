# MediSync Robot Status V4

12 秒 · 1920 × 1080 · 30 fps。Studio ID 為 `RobotStatusPhaseV4`。

| 時間 | 分鏡 | Shotcraft 手法 |
|---|---|---|
| 0–2.5 秒 | 以乾淨背景起鏡，抽取原站 C01、C02、M01 三列。清單底層先揭露，原生列依序入場，在第 58 幀切換至 M01 的原站選中樣式。 | `deck-deal-flyin` 的錯峰進場，縮短為單一清單內的局部運動。 |
| 2.5–5.5 秒 | 原始 Agibot GLB 單獨出場，整機居中，依包圍盒限制視角取景。 | `space-camera-moves` 的 subject-locked orbit，鎖定整機中心，結合小幅推近。 |
| 5.5–9 秒 | 模型移至左側，右側先揭露電量環與溫度弧線，再展開狀態、連線、型號及機器人類型。 | `mosaic-reframe` 的共用取景座標，結合向量描線與資訊層次。 |
| 9–12 秒 | 模型、兩個儀表和資訊各自移回原站位置，完整介面停穩。 | `shot-transitions` 的空間對位與遮罩，用原站素材接手片尾。 |

## 清晰度與模型取景

清單與片尾共用既有 2400 × 1230 原站擷取，清單列按原始像素密度等比呈現。片尾在 1920 × 1080 畫面內以 1696 × 869 顯示。影片資訊段用 HTML 文字與 SVG 儀表，確保大字與弧線維持清晰。M01 的 82% 和 36°C 是同一筆 Demo 遙測，儀表動畫代表讀值揭露，數值維持固定。

主鏡頭直接用 Three.js 與原始 GLB，採 1440 × 800 WebGL 畫布。相機以包圍盒的八角約束投影範圍，讓手端、頭部和底座留在構圖內。鏡頭旋轉固定在整機中心，套用單次由正面偏側至更側前方的環繞。V4 保留原始 UI 版型與欄位，影片鏡頭只呈現整機與關鍵資料。
