## clinical-multi-robot-collaboration-platform-system
A medical multi-robot collaboration platform designed for task scheduling and path planning across multiple healthcare robots. It integrates reinforcement learning and heuristic algorithms to optimize overall operational efficiency.

## 使用語言與版本
- vue 3.5
- .net 8.0
- postgresql
- ROS2 Jazzy
- OPEN-RMF
- Docker desktop
