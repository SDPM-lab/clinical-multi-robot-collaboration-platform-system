# 任務頁面版面與路線修訂

## 畫面與資料來源

- 桌面版採左右兩欄：左側約 400–460px 的半透明面板以分頁切換建立任務與任務排程，預設顯示建立任務；右側透明 Canvas 顯示地圖。樓層、放大、縮小及重設視角在地圖右上角同一排。建立任務的類型及時間改用頁面樣式的選單；時間固定顯示 AM／PM。時長欄位已移除，目前展示資料建立任務仍採 12 分鐘預設值。相同開始時間的任務歸在同一時間列，最多三張任務卡並排；每張仍獨立對應一台機器人，完整起終點與時間可從卡片提示查看。列表不顯示狀態文字或進度條。排程分頁的鉛筆圖示可直接編輯任務時間或刪除任務；刪除前會顯示確認視窗。旁邊的重設圖示會回到目前本地日期。窄螢幕時面板在上、地圖在下。
- 任務表單保留機器人、起終點、日期、時間、優先級及備註；示範資料建立任務目前仍使用 12 分鐘預設時長。地圖點選順序為起點、終點、重新選起點。預設表單已有起終點，地圖在使用者選完兩端前維持橘線；選完後只將既有導航圖上的對應路徑改為綠色。起終點也可從表單的頁面樣式選單選擇。
- F1、放大、縮小及圖示重設鍵置於地圖右上，縮放與拖曳保留。桌面版的程式預設取景放大至 1.12 倍，並向上調整畫面範圍，縮短導覽列下方至房間模型的空白，同時保留左右邊界。加入 `?dispatchDebug=1&cameraDebug=1&modelDebug=1` 可直接開啟派遣頁並調整相機與模型顯示參數；按「儲存預設」寫入此瀏覽器的 localStorage，地圖重設鍵回到儲存的視角。已儲存的相機預設會優先於程式預設縮放；「原始預設」可套用新的程式預設值，之後可再儲存。
- 地圖載入 `public/models/L1__flat.glb` 的 `L1_Solid_Block_Map_v5`。模型中的 `Route_*` 與 `RouteNode_*` 物件在網頁載入時隱藏；`Room_*` 房間保留，原始 GLB 未改動。
- Traffic Editor 的 `L1.building.yaml` 經既有導航產生流程得到 Graph 0；`public/generated/dispatch-route-mapping.json` 將每條 TE 有向邊對應到 GLB 路線折線。底線、高亮及端點共用這套顯示位置，不再直接以整體座標變換畫 TE 直線。
- 純展示線在對應資料中標為視覺用途，不加入導航圖。GLB 與 TE 有三處視覺拓撲差異，處理方式、來源雜湊及驗證結果見 [L1 路線對應說明](dispatch-route-mapping.md)。**目前沒有完成 ROS／GLB 精準座標校正。**

## 未有可確認導航站點的房間區塊

目前 GLB 有展示分支、但 Traffic Editor Graph 0 沒有能直接確認對應的具名目的站點：`Room_director`（主任室）、`Room_men_restroom`（男廁）、`Room_women_restroom`（女廁）。`Room_lift_1` 與 `Room_lift_2`（兩座電梯）也沒有 Graph 0 的房間目的站點及展示分支。這五個區塊不得因畫面橘線而變成可派遣目的地。

`Room_reception_desk` 目前只以既有 `reception_back` 站點代表接待區；此語意對應不表示房間內精確停靠位置已校正。

## Blender 檔案

`blender/scenes/L1__flat.blend` 是分段 Zstandard 壓縮的 Blender 5.0.2 檔案；此環境的 Blender 4.0.2 不能開啟該較新版本。網頁物件名稱及隱藏範圍均已從實際載入的 GLB 場景檢查。
